# Changelog

## Unreleased

## 1.0.0 (2026-11-12)

Day 76 of Udemy's 100 Days of Code as a tested Python package, a Jupyter notebook and a wiki in English, Danish and Bahasa Malaysia.

### Added

- Cleaning, exploration and aggregation functions for the Google Play Store data, in `domain`, `application` and `infrastructure` packages (pandas).
- Plotly chart builders for the pie, donut, bar, scatter, grouped bar and box plot steps.
- A Jupyter notebook that follows the lecture, and a script that writes one screenshot per lecture step to `docs/images/`.
- Tests (88, 100% coverage), including tests on the real course CSV when it is present as `data/apps.csv`.
- README with Windows and Linux set-up, and the wiki in three languages with a Getting-Started page.
- An opengrep scan script to run before every push.
